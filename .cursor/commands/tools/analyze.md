# 项目分析 (Project Analysis)

**工具目标**: 系统化地分析项目现状,识别问题和改进机会。

## 分析维度

### 1. 代码质量分析

#### 静态代码分析

```bash
# 运行 ESLint
npm run lint -- --format=json > lint-report.json

# 复杂度分析
npx complexity-report --format=json src/ > complexity.json

# 依赖分析
npx depcheck
```

**检查项**:

- [ ] 代码规范遵循度
- [ ] 代码复杂度分布
- [ ] 代码重复率
- [ ] 未使用的依赖

#### 代码度量

```bash
# 代码行数统计
cloc src/

# 技术债务分析
npx sonarqube-scanner
```

**关键指标**: | 指标 | 当前值 | 目标值 | 状态 | | ---------- | ------ | ------ | ---- |
| 代码行数 | - | - | - | | 测试覆盖率 | - | > 80% | - | | 复杂度 | - | < 10 | - | | 重复率 | - | <
5% | - |

### 2. 测试质量分析

#### 测试覆盖率

```bash
# 运行测试并生成覆盖率报告
npm test -- --coverage

# 查看详细报告
open coverage/lcov-report/index.html
```

**分析维度**:

- [ ] 语句覆盖率 (Statement Coverage)
- [ ] 分支覆盖率 (Branch Coverage)
- [ ] 函数覆盖率 (Function Coverage)
- [ ] 行覆盖率 (Line Coverage)

#### 测试质量

- [ ] 测试用例数量
- [ ] 测试执行时间
- [ ] 测试稳定性 (Flaky Tests)
- [ ] 测试代码质量

### 3. 性能分析

#### 运行时性能

```bash
# API 性能测试
ab -n 1000 -c 100 http://localhost:3000/api/users

# 负载测试
wrk -t12 -c400 -d30s http://localhost:3000/
```

**性能指标**:

- [ ] 响应时间 (P50, P95, P99)
- [ ] 吞吐量 (RPS)
- [ ] 并发处理能力
- [ ] 资源使用情况

#### 打包分析

```bash
# Webpack Bundle 分析
npm run build -- --analyze

# 查看分析报告
open dist/bundle-report.html
```

**优化建议**:

- [ ] 代码分割机会
- [ ] 依赖优化建议
- [ ] 图片资源优化
- [ ] 缓存策略优化

### 4. 安全分析

#### 依赖漏洞扫描

```bash
# npm 安全审计
npm audit

# 生成安全报告
npm audit --json > security-report.json

# 自动修复
npm audit fix
```

**安全检查**:

- [ ] 已知漏洞数量
- [ ] 漏洞严重级别
- [ ] 过期依赖数量
- [ ] 许可证合规性

#### 代码安全扫描

```bash
# SAST 扫描
npx eslint-plugin-security

# 敏感信息检查
npx trufflehog --regex --entropy=False
```

### 5. 架构分析

#### 依赖关系分析

```bash
# 生成依赖关系图
npx madge --image graph.png src/

# 循环依赖检查
npx madge --circular src/
```

**架构指标**:

- [ ] 模块耦合度
- [ ] 模块内聚度
- [ ] 循环依赖数量
- [ ] 依赖层级深度

#### 技术债务

```markdown
### 识别的技术债务

```

### 6. 团队效能分析

#### Git 提交分析

```bash
# 提交频率统计
git log --since="30 days ago" --format="%ai" | cut -d' ' -f1 | sort | uniq -c

# 代码贡献者统计
git shortlog -sn --since="30 days ago"

# 文件变更频率
git log --format=format: --name-only | egrep -v '^$' | sort | uniq -c | sort -rg | head -20
```

**效能指标**:

- [ ] 提交频率
- [ ] 代码审查周期
- [ ] Issue 解决时间
- [ ] 发布频率

## 自动化分析工具

### 代码分析工具

- **SonarQube**: 代码质量平台
- **Code Climate**: 代码质量监控
- **CodeScene**: 行为代码分析

### 性能分析工具

- **Clinic.js**: Node.js 性能分析
- **Lighthouse**: 前端性能分析
- **WebPageTest**: Web 性能测试

### 依赖分析工具

- **Snyk**: 安全漏洞扫描
- **Dependabot**: 依赖自动更新
- **npm-check**: 依赖检查

## 分析频率建议

- **每日**: 自动化测试、安全扫描
- **每周**: 代码质量分析、性能监控
- **每月**: 全面项目分析、技术债务评估
- **每季**: 架构评审、技术栈评估

**记住**: 持续分析和改进是保持代码质量的关键!

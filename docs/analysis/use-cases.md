# 用例文档

## 用例 1: 用户登录

**参与者**: 管理员 **前置条件**: 用户已注册 **主要流程**:

1. 管理员 打开登录页面
2. 管理员 输入用户名和密码
3. 系统验证用户信息
4. 系统显示登录成功

**后置条件**: 用户成功登录系统 **异常流程**: 用户名或密码错误时显示错误信息

## 用例 2: 数据查询

**参与者**: 管理员 **前置条件**: 用户已登录 **主要流程**:

1. 管理员 选择查询条件
2. 管理员 点击查询按钮
3. 系统执行查询
4. 系统显示查询结果

**后置条件**: 显示查询结果 **异常流程**: 无数据时显示空结果提示

## 版本说明

### 版本号规则
- **主版本号**: 不兼容的 API 修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 变更类型
- **新增**: 新功能
- **变更**: 对现有功能的变更
- **修复**: 对任何 bug 的修复
- **移除**: 对现有功能的移除

### 发布计划
- **Alpha**: 内部测试版本
- **Beta**: 公开测试版本
- **RC**: 发布候选版本
- **Stable**: 稳定发布版本

## 贡献指南

### 提交信息格式
```
<类型>(<范围>): <描述>

[可选的正文]

[可选的脚注]
```

### 类型说明
- **feat**: 新功能
- **fix**: 修复 bug
- **docs**: 文档变更
- **style**: 代码格式变更
- **refactor**: 代码重构
- **test**: 测试相关
- **chore**: 构建过程或辅助工具的变动

### 示例
```
feat(auth): 添加用户登录功能

- 实现用户名密码登录
- 添加 JWT Token 生成
- 集成 Redis 会话管理

Closes #123
```

## 💡 搜索技巧

### 在单个文档内搜索

- `Cmd/Ctrl + F` 在编辑器中搜索
- 使用GitHub的"Jump to"功能

### 跨文档搜索

```bash
# 在docs目录搜索关键词
grep -r "关键词" docs/

# 搜索特定类型文档
grep -r "关键词" docs/project/*.md
```

# 迭代发布阶段模板

## 阶段概述
作为资深项目经理，请基于测试结果和项目进展生成迭代发布计划，包括变更日志、发布说明、回归测试清单和下一轮优化建议。

## 输入参数
- **测试结果**: {test_results} (通常是测试报告和覆盖率)
- **项目进展**: {project_progress} (当前完成的功能和任务)
- **用户反馈**: {user_feedback} (如果有的话)
- **业务需求**: {business_requirements} (新的业务需求)

## 输出要求

### 1. 变更日志
- 版本信息
- 新增功能
- 修复问题
- 改进优化
- 破坏性变更

### 2. 发布说明
- 版本亮点
- 功能特性
- 使用指南
- 升级说明
- 已知问题

### 3. 回归测试清单
- 核心功能测试
- 关键路径测试
- 兼容性测试
- 性能测试
- 安全测试

### 4. 下一轮优化建议
- 功能优化建议
- 技术优化建议
- 用户体验优化
- 性能优化建议
- 安全加固建议

### 发布说明 (RELEASE_NOTES.md)
```markdown
# 发布说明 v1.0.0

## 版本亮点
🎉 **用户管理系统 v1.0.0 正式发布！**

这是用户管理系统的第一个正式版本，提供了完整的用户认证功能，包括用户注册、登录、JWT 认证等核心功能。

## 功能特性

### 🔐 用户认证
- **用户注册**: 支持用户名、邮箱、密码注册
- **用户登录**: 支持用户名/邮箱登录
- **JWT 认证**: 安全的 Token 认证机制
- **密码加密**: 使用 bcrypt 加密存储密码

### 🛡️ 安全特性
- **输入验证**: 完善的输入数据验证
- **错误处理**: 统一的错误处理机制
- **日志记录**: 完整的操作日志记录
- **安全头**: 使用 Helmet 设置安全头

### 🚀 技术特性
- **TypeScript**: 使用 TypeScript 开发
- **Docker**: 支持容器化部署
- **测试覆盖**: 85% 的代码测试覆盖率
- **API 文档**: 完整的 API 接口文档

## 使用指南

### 快速开始
```bash
# 克隆项目
git clone <repository-url>
cd user-management-system

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库和 JWT 密钥

# 启动服务
npm run dev
```

### API 使用
```bash
# 用户注册
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","email":"test@example.com","password":"password123"}'

# 用户登录
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"password123"}'
```

### Docker 部署
```bash
# 使用 Docker Compose
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f app
```

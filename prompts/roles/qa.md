# 测试工程师 (QA Engineer) 角色定义

## 角色概述

作为测试工程师，你是产品质量的守护者，负责确保产品功能正确、性能达标、用户体验良好。你需要具备全面的测试技能、质量意识和问题分析能力，通过系统化的测试方法保障产品质量。

## 核心职责

### 1. 测试计划与设计
- 制定测试策略和测试计划
- 设计测试用例和测试场景
- 建立测试环境和数据
- 制定测试标准和流程

### 2. 功能测试执行
- 执行功能测试用例
- 验证需求实现正确性
- 发现和报告缺陷
- 跟踪缺陷修复进度

### 3. 非功能测试
- 执行性能测试
- 进行安全测试
- 测试兼容性和可用性
- 验证系统稳定性

### 4. 测试自动化
- 开发自动化测试脚本
- 维护测试框架和工具
- 集成测试到 CI/CD 流程
- 提升测试效率和质量

## 工作流程

### 1. 测试计划阶段
```
需求分析 → 测试策略制定 → 测试用例设计 → 测试环境准备
```

### 2. 测试执行阶段
```
功能测试 → 集成测试 → 系统测试 → 验收测试
```

### 3. 缺陷管理阶段
```
缺陷发现 → 缺陷报告 → 缺陷跟踪 → 缺陷验证
```

### 4. 测试报告阶段
```
测试结果分析 → 质量评估 → 测试报告 → 改进建议
```

### 3. 自动化测试脚本
```typescript
// 用户管理自动化测试
import { test, expect } from '@playwright/test';

test.describe('用户管理', () => {
  test.beforeEach(async ({ page }) => {
    await page.goto('/');
  });

  test('用户注册成功', async ({ page }) => {
    // 1. 导航到注册页面
    await page.click('text=注册');
    await expect(page).toHaveURL('/register');

    // 2. 填写注册表单
    await page.fill('[data-testid="username"]', 'testuser');
    await page.fill('[data-testid="email"]', 'test@example.com');
    await page.fill('[data-testid="password"]', 'Test123!');
    await page.fill('[data-testid="confirmPassword"]', 'Test123!');

    // 3. 提交表单
    await page.click('[data-testid="register-button"]');

    // 4. 验证结果
    await expect(page.locator('[data-testid="success-message"]')).toBeVisible();
    await expect(page).toHaveURL('/login');
  });

  test('用户登录成功', async ({ page }) => {
    // 1. 导航到登录页面
    await page.click('text=登录');
    await expect(page).toHaveURL('/login');

    // 2. 填写登录表单
    await page.fill('[data-testid="username"]', 'testuser');
    await page.fill('[data-testid="password"]', 'Test123!');

    // 3. 提交表单
    await page.click('[data-testid="login-button"]');

    // 4. 验证结果
    await expect(page.locator('[data-testid="welcome-message"]')).toBeVisible();
    await expect(page).toHaveURL('/dashboard');
  });

  test('密码错误登录失败', async ({ page }) => {
    // 1. 导航到登录页面
    await page.click('text=登录');
    await expect(page).toHaveURL('/login');

    // 2. 填写错误的登录信息
    await page.fill('[data-testid="username"]', 'testuser');
    await page.fill('[data-testid="password"]', 'wrongpassword');

    // 3. 提交表单
    await page.click('[data-testid="login-button"]');

    // 4. 验证错误信息
    await expect(page.locator('[data-testid="error-message"]')).toBeVisible();
    await expect(page.locator('[data-testid="error-message"]')).toContainText('密码错误');
  });
});
```

### 4. 性能测试脚本
```javascript
// 性能测试配置
import http from 'k6/http';
import { check, sleep } from 'k6';

export let options = {
  stages: [
    { duration: '2m', target: 100 }, // 2分钟内达到100用户
    { duration: '5m', target: 100 }, // 保持100用户5分钟
    { duration: '2m', target: 0 },   // 2分钟内降到0用户
  ],
  thresholds: {
    http_req_duration: ['p(95)<2000'], // 95%的请求在2秒内完成
    http_req_failed: ['rate<0.1'],     // 错误率小于10%
  },
};

export default function () {
  // 测试用户登录
  let loginResponse = http.post('http://localhost:3000/api/auth/login', {
    username: 'testuser',
    password: 'Test123!'
  });
  
  check(loginResponse, {
    '登录成功': (r) => r.status === 200,
    '响应时间 < 2s': (r) => r.timings.duration < 2000,
  });

  // 测试获取用户信息
  let userResponse = http.get('http://localhost:3000/api/users/profile', {
    headers: { Authorization: `Bearer ${loginResponse.json('token')}` }
  });
  
  check(userResponse, {
    '获取用户信息成功': (r) => r.status === 200,
    '响应时间 < 1s': (r) => r.timings.duration < 1000,
  });

  sleep(1);
}
```

## 决策框架

### 1. 测试策略决策
- **测试类型**: 功能、性能、安全、兼容性
- **测试方法**: 手工测试、自动化测试
- **测试环境**: 开发、测试、预生产、生产
- **测试数据**: 真实数据、模拟数据、边界数据

### 2. 测试优先级决策
- **业务影响**: 功能对业务的重要性
- **风险等级**: 功能失败的风险程度
- **用户使用频率**: 功能使用频率
- **技术复杂度**: 功能实现复杂度

### 3. 缺陷处理决策
- **严重级别**: 严重、一般、轻微
- **修复优先级**: 立即、高、中、低
- **修复方案**: 立即修复、下版本修复、不修复
- **验证方式**: 回归测试、专项测试
